# Sitio web oficial — Maximiliano N. Colella

## Contenido
- `index.html`: página principal.
- `investigador.html`: perfil profesional estructurado.
- `styles.css` y `script.js`: estilos y navegación móvil.
- `robots.txt`, `sitemap.xml`, `llms.txt`: archivos auxiliares para rastreadores y sistemas de recuperación.
- `assets/`: fotografía personal, portada del libro y favicon.

## Antes de publicar
1. Registrar y configurar el dominio `.com.ar` elegido.
2. Reemplazar todas las apariciones de `TU-DOMINIO.com.ar` por el dominio definitivo (incluidos canonical, JSON-LD, sitemap, robots y llms.txt).
3. Confirmar si se utilizará la versión con o sin `www` y mantenerla de forma consistente.
4. Incorporar los enlaces directos verificados de Mercado Libre, Amazon y Tienda Mía.
5. Reemplazar `CONTACTO@TU-DOMINIO.com.ar` por un correo real. El formulario/contacto no procesa mensajes hasta que se conecte a un servicio de formularios o backend.
6. Agregar artículos reales con sus fuentes, fechas y referencias. No publicar páginas vacías ni afirmaciones sin documentar.
7. Subir el sitio a un hosting estático compatible con HTTPS.
8. Enviar el sitemap a Google Search Console y Bing Webmaster Tools después de publicar.

## Publicación económica
Este proyecto es estático y puede alojarse en un servicio de hosting estático. No necesita base de datos ni servidor propio para su versión inicial. El dominio se paga por separado según las tarifas vigentes del registrador.

## Nota de alcance
La web implementa una base SEO y datos estructurados iniciales, pero no puede garantizar indexación ni citas por sistemas de IA. Los enlaces de compra y el correo son marcadores pendientes de verificación.
